# Olá Mundo V1 — Minha Primeira Jornada

## Sobre o projeto

Este é meu primeiro projeto desenvolvido em Python,
representando o início da minha jornada na programação.

O projeto combina programação e poesia, trazendo
mensagens de reflexão, apresentação pessoal e
um cálculo simples de idade.

## Data de criação

10/10/2026

## Conhecimentos aplicados

- Lógica de programação
- Função print()
- Variáveis
- Tipos de dados
- Operadores aritméticos
- Cálculo de idade

## Tecnologias utilizadas

- Python
- Git
- GitHub

## Como executar

Com o Python instalado, execute no terminal:

python ola-mundo-v1.py

## Evolução do projeto

Esta primeira versão foi preservada para registrar
meu início na programação e permitir uma comparação
com as próximas versões.
